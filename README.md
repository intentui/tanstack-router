# Intent UI TanStack Router Starter

React and Intent UI starter with TanStack Router, Tailwind CSS, and [Vite+](https://viteplus.dev/guide).

## Development

```sh
bun install
bun run dev
```

The development server runs on port 3001.

## Commands

- `bun run dev` — start the Vite+ development server.
- `bun run build` — create the production build in `dist/`.
- `bun run serve` — preview the production build.
- `bun run check` — check formatting, lint, and TypeScript types.
- `bun run check:fix` — format files and apply safe lint fixes.
- `bun run format` — format files with Oxfmt.
- `bun run lint` — lint with Oxlint and check types.
- `bun run typecheck` — check TypeScript types only.

Build, lint, and formatter settings live in `vite.config.ts`. Generated routes are excluded from lint and formatting.

See the [Intent UI documentation](https://intentui.com/docs/getting-started/introduction).
